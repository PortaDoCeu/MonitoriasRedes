% TEMA COASTAL NOITE ────────────────────────────────────────────────────────
% Paleta base: Cerulean · Tropical Teal · Light Yellow → virada para a noite
%
% Sentimento: meia-noite na praia, oceano que brilha sob o luar,
%   estrelas esparsas, silêncio que se move, água escura com reflexos
%   prateados, a lua como única fonte de calor — discreta, alta, fria.
%
% Decisões estéticas:
%   • Fundo quase-preto azulado — não preto puro, mas azul de profundidade
%   • O oceano entra como mancha viva: cerulean escuro com reflexos teal
%   • A lua é uma presença, não um ícone — halo difuso, centro branco
%   • Estrelas: pontos irregulares em tamanhos variados, nunca em grade
%   • O texto é branco-azulado — como areia clara vista de noite
%   • O coral sai. Entra o prateado-teal como acento único
% ──────────────────────────────────────────────────────────────────────────
